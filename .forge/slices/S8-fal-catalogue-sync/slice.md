## Delivers (one sentence, end-to-end)
The app offers fal's current frontier generation models — MiniMax H3 Max, Seedance 2.5 (native 30s), latest Kling/Veo/Wan/LTX/Grok video + FLUX.2/GPT-Image-2.5/Nano Banana/Seedream/Qwen image — each verified against fal's live schema before it is offered, and a reusable fal→registry diff tool so the catalogue can be re-synced later.

## Ground truth (verified this session — see explore reports)
- Registry = vendored Higgsfield `MODELS.md` + 12 hand-authored picker-only specs (registry.rs:1394). Adding a model = spec + `priced_routes` arm (registry.rs:568) + `JOB_TYPES` (registry.rs:266) + `FAL_ROUTE_MODES` entry (media.rs:599, fixed-size array) + array-length bumps + test updates. ~40–60 lines each.
- `fal_catalogue.rs` caches fal's live index (`GET https://fal.ai/api/models?page=N`, unauthenticated, 1,418 items, snapshot 2026-08-05) — built, tested, WIRED TO NOTHING. Documented refresh example `dump_fal_catalogue` does not exist. No fal→registry reverse diff exists.
- `fal_schema.rs` + `examples/audit_fal.rs` probe fal's per-endpoint OpenAPI with NO key and NO money — the free verification gate.
- Route-suffix resolver (`resolve_endpoint`, media.rs:862) IS built and wired (app.rs:276-296); backlog #4 bullet 1 + `docs/FIRST-LIGHT.md:32-95` are STALE. Residual risk: a slug fal doesn't serve can't be detected without probing (media.rs:721-733) → every imported slug must pass audit_fal.
- Newest MiniMax on fal = H3 Max (`minimax/h3-max/{text-to-video,image-to-video,reference-to-video,camera-controls,director}`, `minimax/h3-max-turbo/{t2v,i2v}`), 5–15s, 2K; `minimax_hailuo` 2.3's fal slug is dead (pinned `FAL_MISSING_ROUTES`, Higgsfield-only). Seedance 2.5 (`bytedance/seedance-2.5/{text-to-video,image-to-video,reference-to-video}`, 4–30s, 720p, audio) is absent. New slugs are vendor-namespaced (`minimax/…`, `bytedance/…`, `openai/…`, `alibaba/…`, `xai/…`) — not only `fal-ai/…`.
- Owner decision: curated frontier gen models per use case, verified — NOT a bulk mirror of all 1,418.

## Approach + why now
Owner: the catalogue is stale vs fal (no H3 Max, no Seedance 2.5). Sync first because it delivers native 30s (Seedance 2.5) and the frontier models immediately and cheaply; the Storyboard/stitch slices (S9–S11) build on it. Build the diff tool FIRST (reusable, de-risks), import from live data, verify every slug free via audit_fal, never add an unprobed slug.
